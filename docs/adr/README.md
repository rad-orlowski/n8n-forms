# Consulting ADRs

This directory contains Architecture Decision Records (ADRs) — binding records
of significant architectural and process decisions for this project.

**Before changing architecture or established patterns, any coding agent MUST:**

1. Read this index (`README.md`) to get an overview of active decisions.
2. Read every ADR whose `applies-to` globs match files you are about to touch.
3. Read all ADRs marked `global: true` — they apply everywhere, unconditionally.
4. Do **not** override or re-litigate an `accepted` decision. If your change
   requires violating one, surface the conflict explicitly and propose a
   superseding ADR instead of silently proceeding.
