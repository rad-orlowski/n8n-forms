# n8n-forms (app)

The React/Vite app inside this repo. See the [root README](../README.md) for full documentation.

## Commands

```bash
bun install
bun dev              # dev server at http://localhost:5173
bun run build        # Vite build → dist/
./bundle-artifact.sh # build + inline → ../forms.html
```

Set webhook URLs in `.env` (copy `.env.example`).
